# Dataset Source

本實驗使用 UCI Machine Learning Repository 的 [SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms)，共 5,574 筆帶有 ham／spam 標籤的簡訊。

- Creators：Tiago Almeida、Jos Hidalgo
- DOI：[`10.24432/C5CC84`](https://doi.org/10.24432/C5CC84)
- License：Creative Commons Attribution 4.0 International（CC BY 4.0）

建議引用：

> Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84

Notebook 會從 UCI 下載資料至本機 `data/`。該資料夾已列入 `.gitignore`，倉庫只保存程式與彙總結果。
